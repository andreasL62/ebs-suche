# EBS Zeichnungssuche

Offline-Web-App zum Durchsuchen eines Zeichnungswerks (PDF) auf iPhone/iPad, Android und PC.

Dieses Repository enthält **nur den Programmcode**. Zeichnungen und Suchdaten sind nicht enthalten –
sie werden auf jedem Gerät lokal aus einer separat verteilten PDF und einer Datendatei importiert
und verlassen das Gerät nicht.

- Mehrwort-Suche (auch unscharf, tolerant gegenüber Lesefehlern der Texterkennung)
- Suche nach Ebs-Nummern, Inhaltsbaum, Filter nach Bauarten und Gültigkeitsvermerken
- Antippbare Verweise auf andere Blätter mit Zurück-Navigation
- PDF-Darstellung mit [pdf.js](https://mozilla.github.io/pdf.js/) (Apache-2.0)
